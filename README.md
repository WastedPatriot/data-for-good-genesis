# DataForEarth

Platform for ethical data practices and environmental initiatives.

> **Lovable Project:** https://lovable.dev/projects/492e7fd1-6e30-483a-bddd-e3199d936946

## 📁 Repository Structure

This repository contains two applications:

### 🌐 Website (Main Project)
React-based web platform for:
- Dataset marketplace
- Data contribution
- Environmental project showcase
- User authentication
- Admin dashboard

**Tech Stack:** React, TypeScript, Supabase, Stripe, Tailwind CSS

**Entry Point:** `src/App.tsx`

### 🖥️ Machine Agent (Desktop App)
Electron-based automation tool for Ubuntu Linux:
- Automated dataset publishing
- Badge code management
- Revenue analytics
- Background automation
- Systemd integration

**Tech Stack:** Electron, React, TypeScript, Chart.js

**Location:** `machine-agent-gui/`

## 🚀 Quick Start

### Website
```bash
npm install
npm run dev
```

### Machine Agent
```bash
cd machine-agent-gui
npm install
npm run dev
```

## 📦 Building

### Website (Production)
```bash

```
